# tcm-skill
TCM-SKILL


整理建立一个 中医药特效处方收集skill,

目前最系统的中医药特效处方收集成果是《中医药特效处方》，收录了2000余款针对360多种常见病和疑难杂症的处方，涵盖神经、循环、消化、呼吸、妇科、儿科等16个专科领域。

处方收录特点
疾病覆盖面广：涵盖神经系统、循环系统、消化系统、呼吸系统、泌尿生殖系统、妇科、儿科等。

条目完整：每病种下设概要、处方组成、用法、功效、医案、注意事项。

临床实用性：多数方剂为历代名医或民间验证方，强调药物配伍与疗效时效。

特色章节：专设肿瘤防治、养生长寿方，如“冬补延寿汤”“乌鸡白凤汤”等。

注意事项
处方仅供参考：中医讲究辨证论治，不能直接套用。

需专业指导：建议在合格中医师指导下使用，避免自行配伍。

现代应用：部分方剂已被纳入临床实践，但仍需结合个体体质与病情。
